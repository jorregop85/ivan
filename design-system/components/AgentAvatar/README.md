# AgentAvatar

Avatar ilustrado de cada agente del equipo virtual: disco en su color suave, cara simple y un rasgo propio (anteojos de Iván, melena de Clara, cola de Andrea, rulos de Olivia, pelo largo de Sofía, moño de Elena, escudo de Vera).

- `agent`: `ivan` · `clara` · `andrea` · `olivia` · `sofia` · `elena` · `vera`.
- `size`: 20 (en línea), 32 (tarjetas), 40 (notas), 48+ (conversación).
- `label`: `true` muestra nombre + etiqueta **IA** + especialidad; `"name"` solo nombre + IA.
- La primera aparición de un agente en cada pantalla lleva `label`: la etiqueta IA es obligatoria, nunca se oculta que son agentes.
- Siempre ilustrado, nunca foto. El nombre accesible es "<Nombre>, agente de IA".
