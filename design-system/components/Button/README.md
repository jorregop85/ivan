# Button

Botón de acción. Alto mínimo 48px (`tap-min`), texto en verbo + objeto.

- `primary`: una sola acción principal por pantalla ("Enviar registro", "Pedir informe a Iván").
- `secondary`: acciones alternativas; borde `line-strong`.
- `quiet`: salir, omitir, "Ahora no".
- `block`: ancho completo, para el pie de hojas en celular.
