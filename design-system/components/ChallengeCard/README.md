# ChallengeCard

Microprácticas de la semana: casilla para marcar realizado y registro rápido de cómo respondió.

- Cada desafío va ligado a un objetivo y a un momento del día (`moment`).
- Al marcarlo aparece "¿Cómo respondió?" con respuestas rápidas.
- Texto en instrucción concreta, en segunda persona.
