# StatusPill

Semáforo de un objetivo: avanzando ↗, estancado →, retrocediendo ↘, en medición ◌.

- El ícono y la palabra siempre acompañan al color: nunca solo color.
- Retrocediendo usa terracota suave (`status-retrocediendo`), no rojo alarma.
- "En medición" significa que aún se construye la línea base: el objetivo no muestra meta numérica.
