# Sparkline

Mini gráfico de tendencia para tarjetas de objetivo.

- Línea `primary` de 2.5px con punto final; línea base punteada `ink-muted`; meta en `status-avanzando-ink`.
- Con `status="midiendo"` la línea se vuelve punteada y la meta no se dibuja.
- Siempre acompañado de la cifra en texto ("6 de 10 esta semana").
