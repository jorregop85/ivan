# SkillState

Estado de una habilidad en el perfil de punto de partida: consolidada, emergente, ausente o sin datos.

- Los cuatro puntos se distinguen por luminosidad y borde (lleno oscuro, medio, claro, punteado vacío), no solo por tono.
- Con `children` muestra el nombre de la habilidad; el estado queda disponible para lectores de pantalla.
- "Ausente" no es un fracaso: en el perfil se lista después de las fortalezas.
