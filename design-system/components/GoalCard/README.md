# GoalCard

Tarjeta de un objetivo activo en la vista general: especialista a cargo, semáforo, nombre, cifra y tendencia.

- Mostrar de 3 a 5 por vista; el orden lo decide Iván (primero lo que cambió).
- `metric` es una frase corta con número real ("6 de 10 esta semana"). Objetivos en medición muestran "Construyendo la línea base".
- Con `href` toda la tarjeta enlaza a la ficha del objetivo.
