# EvidenceItem

Una entrada de la línea de tiempo de evidencia: origen con ícono, fecha, cita literal y enlace a la fuente.

- `source`: `aba` · `casa` · `colegio` · `psiquiatra`.
- La cita es literal, entre comillas, en estilo `quote`. No se resume ni se corrige.
- Toda afirmación del sistema enlaza a su fuente (`href`, `kind` = `audio` o `registro`).
